# 議事録作成の定期実行

| 定期実行 | いつ | 何をする | 結果の出し先 |
|---|---|---|---|
| 週1回の未処理の文字起こしチェック | 金曜 18:00 | ~/Downloads の直近 14 日の文字起こしのうち、議事録になっていないものを一覧にする | bot の Home チャットで続けて実行し、結果もそこへ。未処理が無ければ何も出さない |

- 議事録の作成そのものは定期実行にしない。一覧を見たオーナーが、作るものをチャットで頼む。
- Home チャットで続けて実行する(`--runs-in chat`)と、一覧を見てそのまま「1 と 3 の議事録を作って」と頼める。
- 時刻はホストの時刻で動く。別のタイムゾーンで動かしたいときは `--timezone` を付ける。

## 作り方

bot のチャットで「次のプロンプトで、毎週金曜 18:00 の定期実行をこのチャットで作って」と頼むと、bot が作る。自分で作るときは、下のプロンプトをファイル(例 `weekly-transcripts.txt`)に保存し、次のコマンドを使う。

```sh
orca automations create --bot "議事録作成" --name "週1回の未処理の文字起こしチェック" \
  --trigger "FREQ=WEEKLY;BYDAY=FR;BYHOUR=18;BYMINUTE=0" --runs-in chat --results-to chat \
  --missed-run-grace-minutes 720 \
  --prompt "$(cat weekly-transcripts.txt)"
```

## 週1回の未処理の文字起こしチェック

- いつ: `FREQ=WEEKLY;BYDAY=FR;BYHOUR=18;BYMINUTE=0`(金曜 18:00)
- 文字起こしの置き場が ~/Downloads でなければ、手順 2 のフォルダを書き換える。

```text
週1回の未処理の文字起こしチェック。
1. この bot のフォルダの projects.md を読む。
2. ~/Downloads で直近14日に更新された文字起こし（.txt と、Teams の会議名の .docx。PDF・pptx・画像・請求書などは対象外）を列挙する。
3. 各ファイルについて、projects.md の対応表で該当プロジェクトを推定し、その議事録の置き場に同じ会議日（ファイル更新日の前後1〜2日）・同じ会議の議事録があるかを確かめる。
4. 議事録が無いものだけを、ファイル名・推定プロジェクト・推定の根拠を1行ずつで一覧にして報告する。プロジェクトが判断できないものは「どれか要確認」と書く。議事録の作成はまだ始めない（オーナーの指示を待つ）。
5. 未処理が無ければ NO_REPLY だけを返す。
```
